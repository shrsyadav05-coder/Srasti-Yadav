Week 2 – Footprinting & Network Scanning

Project Overview

This project was completed as part of my Cybersecurity and Ethical Hacking Internship Program at Networkwalks.

The project focuses on two important phases of penetration testing: Footprinting & Reconnaissance and Network Scanning.

Modules Completed

- W2-PM1: Footprinting using Multiple Kali Linux Tools
- W2-PM5: Network Scanning using Zenmap

Tools Used

- Kali Linux
- WHOIS
- WhatWeb
- Nslookup
- cURL
- WAFW00F
- DNSRecon
- Zenmap (Nmap GUI)
- Windows CMD

Objectives

- Gather publicly available domain information.
- Identify website technologies and DNS records.
- Inspect HTTP response headers.
- Understand Web Application Firewall detection.
- Identify live hosts on an authorised local network.
- Understand IP and MAC address identification.
- Generate a network topology.

Learning Outcomes

- Gained practical experience with reconnaissance tools.
- Learned basic DNS enumeration and web technology fingerprinting.
- Understood network discovery using Zenmap.
- Improved cybersecurity documentation and reporting skills.
- Learned the importance of authorised security testing.
