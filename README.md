Kali Linux Setup Using Oracle VirtualBox

Project Overview

This project documents my hands-on experience setting up Kali Linux in Oracle VirtualBox and configuring its network settings.

Tools & Technologies Used

- Kali Linux
- Oracle VirtualBox
- Linux Terminal
- NAT & Host-Only Adapter
- IPv4 Configuration

Project Objectives

- To install and explore Kali Linux in a virtual environment.
- To understand VirtualBox network configurations.
- To configure NAT and Host-Only networking.
- To learn basic Linux commands and network connectivity testing.

Challenges Faced

During the setup, I encountered a few challenges:

- Configuring VirtualBox network settings.
- Setting up the  NATNetwork Adapter.
- Configuring IPv4 address and network settings.
- Troubleshooting network connectivity issues.

Learning Outcomes

Successfully completed the Kali Linux setup and gained practical knowledge of virtualization, Linux environments and basic networking concepts.
